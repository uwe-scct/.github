# UWE School of Computing and Creative Technologies

Welcome to the official GitHub organisation for the UWE Bristol School of Computing and Creative Technologies.

## Who can join?
- UWE Computing students
- UWE academic staff
- Researchers and project collaborators

## What you'll find here
- Student coursework repositories
- Programming projects
- Research and development work
- Collaborative group projects
- Open-source contributions

## Getting Started
1. Sign in with your GitHub account.
2. Request access from your module leader or administrator.
3. Accept the organisation invitation.
4. Start collaborating and sharing your work.

Learn more: https://www.uwe.ac.uk/
